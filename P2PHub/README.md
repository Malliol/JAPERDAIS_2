# ОСГОворим

[![tests](https://github.com/Malliol/p2phub/actions/workflows/ci.yml/badge.svg)](https://github.com/Malliol/p2phub/actions/workflows/ci.yml)

Децентрализованное приложение для обмена **сообщениями и файлами** напрямую
между пользователями (peer-to-peer), без центрального сервера. Работает как
обычный сайт в браузере и устанавливается на телефон (Android и iPhone) как
**PWA** — без магазинов и без Mac.

> Статус проекта: 🟢 этапы 1–4 готовы — PWA + передача файлов (WebTorrent) +
> чат (WebRTC). Осталась проверка на реальных телефонах и Этап 5 (улучшения).
>
> Живой сайт: https://malliol.github.io/p2phub/

---

## Что это будет уметь (простыми словами)

- Открыл сайт → можешь отправить файл другому человеку **напрямую**, файл не
  лежит ни на каком сервере.
- Можешь переписываться в чате, и сообщения тоже идут напрямую между устройствами.
- Сайт можно «установить» на телефон одной кнопкой («Добавить на главный экран»).

## Как это вообще возможно без сервера?

Файлы передаются по технологии **WebTorrent** — это торрент прямо в браузере.
Когда ты раздаёшь файл, другой человек скачивает его кусочками напрямую у тебя
(и у других, кто уже скачал). Сообщения идут по **WebRTC** — это прямое
соединение между двумя браузерами.

Подробнее — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Как сайт станет приложением на телефоне (без Mac)

1. Делаем обычный сайт (HTML/CSS/JS).
2. Добавляем два файла — `manifest.json` и `service-worker.js`. Сайт становится
   **PWA**: его можно установить на любой телефон (Android и iPhone) прямо из
   браузера кнопкой «Добавить на главный экран». Mac и магазины не нужны.

Подробный план — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Структура репозитория (что где лежит)

```
ОСГОворим/
├── index.html            ← страница приложения
├── style.css             ← оформление
├── app.js                ← логика: DOM, WebTorrent, PeerJS (ES-модуль)
├── lib.js                ← чистые функции (их покрывают тесты)
├── manifest.json         ← паспорт PWA
├── service-worker.js     ← кэш / офлайн
├── icons/                ← иконки приложения (логотип ОСГО)
├── tests/                ← тесты
│   ├── cases.js          ← общие тест-кейсы
│   ├── lib.test.js       ← запуск через Node (node --test)
│   └── run.html          ← запуск прямо в браузере
├── README.md             ← этот файл, общее описание
├── docs/                 ← вся документация
│   ├── ARCHITECTURE.md   ← как устроено технически
│   ├── ROADMAP.md        ← пошаговый план разработки
│   ├── GLOSSARY.md       ← словарик терминов для новичка
│   ├── SERVERS.md        ← роли серверов (хостинг, signaling, push)
│   ├── NOTIFICATIONS.md  ← разбор уведомлений в P2P
│   └── TESTING.md        ← как запускать тесты
└── .gitignore            ← что не класть в репозиторий
```

## Тесты

Чистые функции из `lib.js` покрыты тестами. Запустить можно двумя способами:

- **В браузере (без установки):** открой `tests/run.html` — увидишь список
  пройденных/проваленных проверок.
- **Через Node:** `node --test` (то же делает GitHub Actions при каждом пуше).

Подробнее — в [docs/TESTING.md](docs/TESTING.md).

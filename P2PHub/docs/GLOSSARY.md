# Словарик терминов (для новичка)

Короткие объяснения слов, которые встретятся в проекте. Без этого документация
выше может казаться «китайской грамотой» — возвращайся сюда, когда что-то непонятно.

| Термин | Простыми словами |
|---|---|
| **HTML** | «Скелет» страницы: где текст, где кнопки, где картинки. |
| **CSS** | «Одежда» страницы: цвета, шрифты, расположение, красота. |
| **JavaScript (JS)** | «Мозги» страницы: что происходит при нажатии кнопок, логика. |
| **Браузер** | Программа, в которой открывают сайты (Chrome, Safari, Firefox). |
| **Сервер** | Чужой компьютер в интернете, который обычно хранит данные и раздаёт сайт. |
| **P2P (peer-to-peer)** | «Равный с равным» — устройства общаются напрямую, без сервера-посредника. |
| **Пир (peer)** | Один из участников P2P-сети, то есть чьё-то устройство. |
| **Децентрализация** | Нет единого главного сервера; данные и нагрузка распределены между всеми. |
| **WebTorrent** | Торрент, который работает прямо в браузере. Файлы качаются кусочками у других пиров. |
| **WebRTC** | Технология прямого соединения между двумя браузерами (видеозвонки, чат, файлы). |
| **Signaling-сервер** | Маленький сервер, который только «знакомит» двух пиров, чтобы они соединились напрямую. Сами данные через него не идут. |
| **Трекер (tracker)** | Сервис, который помогает торрент-пирам найти друг друга. |
| **PWA** | Progressive Web App — сайт, который можно «установить» на телефон как приложение. |
| **manifest.json** | Файл-«паспорт» PWA: имя приложения, иконка, цвета. |
| **Service Worker** | Скрипт, который работает в фоне: кэширует сайт, чтобы он открывался даже без интернета. |
| **PWABuilder** | Бесплатный сайт, который из PWA делает пакеты для Google Play и App Store. |
| **TWA** | Trusted Web Activity — способ упаковать PWA в Android-приложение. |
| **Xcode** | Программа Apple для сборки iPhone-приложений (обычно только на Mac). |
| **GitHub Actions** | Облако, где можно собирать приложения автоматически — в том числе iPhone-сборку без своего Mac. |
| **Git** | Система, которая хранит историю всех изменений в коде. |
| **Репозиторий (репо)** | Папка проекта под управлением Git, со всей историей изменений. |
| **Коммит** | Сохранённая «точка» в истории проекта с описанием, что изменилось. |
| **`.gitignore`** | Список файлов, которые Git должен игнорировать (не сохранять). |

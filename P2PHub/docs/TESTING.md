# Тесты ОСГОворим

> Незнакомые слова — в [GLOSSARY.md](GLOSSARY.md).

## Что тестируем

P2P-части (WebTorrent, WebRTC) зависят от сети и других устройств — их
автоматически тестировать сложно. Поэтому мы вынесли всю **чистую логику**
(без DOM и сети) в `lib.js` и покрыли её тестами:

| Функция | Что проверяем |
|---|---|
| `fmtBytes` | размер в байтах → «2.0 КБ» и т.п. |
| `escapeHtml` | экранирование `< > & " '` (защита чата от инъекций) |
| `isMagnetUri` | строка похожа на корректную magnet-ссылку |
| `trimHistory` | история чата обрезается до последних 200 сообщений |
| `parseHistory` | безопасный разбор истории (мусор → пустой список) |

Тест-кейсы лежат в одном месте — `tests/cases.js` — и переиспользуются
обоими способами запуска ниже.

## Способ 1. В браузере (ничего ставить не нужно)

Открой `tests/run.html` через локальный или онлайн-хостинг (по https) —
увидишь список проверок с галочками и итог внизу.

## Способ 2. Через Node

Нужен установленный [Node.js](https://nodejs.org) (версия 18+):

```
node --test
```

Зависимостей нет — используется встроенный в Node тест-раннер.

## Автотесты в облаке (CI)

Файл `.github/workflows/ci.yml` запускает `node --test` при каждом пуше и
pull request в ветку `main`. Результат виден значком в начале README и на
вкладке **Actions** в GitHub. Так сломанный код видно сразу.

## Как добавить свой тест

1. Открой `tests/cases.js`.
2. Добавь объект в массив `cases`:
   ```js
   { name: "моя проверка", fn: () => eq(fmtBytes(1024), "1.0 КБ") }
   ```
3. Запусти любым способом выше — новый тест подхватится автоматически.
